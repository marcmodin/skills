# No AI slop

A house style for written content. The goal is prose that reads like a person wrote it, not a chatbot.

## How to use this skill

1. Read [WRITING.md](WRITING.md) in full before writing or editing any prose.
2. Apply its rules **while drafting**, not as a post-hoc audit.
3. When editing existing text, pass it against WRITING.md and rewrite anything that violates a rule.

WRITING.md is the single source of truth. Do not work from memory or paraphrase its rules — open it and act on what it says.

The reliable test it ends on: **would the author write this sentence?** If the answer is no, it doesn't go in.
